# 🌐 Scanovich.ai - Landing Page

Многоязычная лендинг-страница для системы анализа звонков с искусственным интеллектом.

## 🎯 Особенности

### 🌍 Многоязычность
- **Русский** - основной язык
- **Английский** - для международного рынка
- **Тайский** - для азиатского рынка

### 💡 Интерактивные элементы
- **Калькулятор экономии** - расчет ROI в реальном времени
- **Адаптивный дизайн** - работает на всех устройствах
- **Анимации** - плавные переходы и эффекты
- **Контактная форма** - для генерации лидов

### 📊 Секции сайта
1. **Hero** - главный экран с калькулятором
2. **Проблемы** - боли ручного анализа
3. **Решение** - преимущества AI системы
4. **Отрасли** - сферы применения
5. **Калькулятор** - детальный расчет экономии
6. **Демо** - видео презентация
7. **Контакты** - форма обратной связи

## 🚀 Запуск

### Простой способ (локальный сервер)
```bash
# Открыть в браузере
open index.html
```

### С локальным сервером (рекомендуется)
```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve .

# PHP
php -S localhost:8000
```

Затем откройте: `http://localhost:8000`

## 💰 Калькулятор экономии

### Формула расчета
```javascript
// Количество аналитиков
analystsNeeded = Math.ceil((calls * timePerCall / 60) / 8)

// Годовая стоимость
totalCost = analystsNeeded * salary * 12 * 1.4

// Экономия
savings = totalCost - aiSystemCost
```

### Параметры по умолчанию
- **Звонков в день**: 5000
- **Зарплата аналитика**: 35,000 руб/мес
- **Время анализа**: 15 минут
- **Стоимость AI**: 200,000 руб/год

## 🌐 Переводы

### Добавление нового языка
1. Добавьте новый объект в `translations.js`:
```javascript
'fr': {
    'nav-benefits': 'Avantages',
    // ... другие переводы
}
```

2. Добавьте кнопку языка в HTML:
```html
<button onclick="changeLanguage('fr')" class="lang-btn" data-lang="fr">🇫🇷 FR</button>
```

3. Обновите функцию `formatCurrency` в `script.js`

### Структура переводов
- **Meta**: заголовки страниц
- **Navigation**: меню навигации
- **Content**: основной контент
- **Forms**: формы и поля ввода

    --secondary-color: #your-color;
}
