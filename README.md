## 💼 **Для кого этот проект?**

Этот проект создан для **любого бизнеса**, где важно качество обслуживания клиентов по телефону:

- 🏥 **Медицинские центры** — контроль записи на прием, консультаций
- 📞 **Call-центры** — оценка работы операторов, соблюдение скриптов
- 🏪 **Ритейл и сервис** — анализ качества консультаций
- 🏦 **Банки и финансы** — контроль продаж, техподдержки
- 🎓 **Образование** — оценка работы менеджеров по продажам

**Текущий кейс:** Система успешно работает в сети диагностических центров (4 филиала, ~80 звонков/час, 24/7).

**Но это только начало!** Архитектура спроектирована так, чтобы легко адаптироваться под **любую отрасль** и **любые скрипты обслуживания**.

## 📋 Что делает система

**Полностью автоматический pipeline (24/7):**

```
input/ (новые аудиозвонки)
  ↓
1. Транскрибация (Whisper Large V3) - RTF 0.027 (37x быстрее!)
  ↓
2. Маскирование PII (Qwen3-30B) - ФИО/телефоны → замаскированы
   + Исправление имён админов (РУ/РЗУ → Арзу)
   + Нормализация адресов через branches.yaml
  ↓
3. Анализ качества (Qwen3-30B) - оценка по 30 критериям скриптов 1.5T/3T
  ↓
4. Сбор в БД (SQLite) - только failed/unknown для аналитики
  ↓
5. Автоматические отчёты:
   • Telegram (09:00 daily, 10:00 weekly)
   • Google Sheets Dashboard (23:00 обновление)
   • Google Sheets все звонки (real-time)
  ↓
output/ + metadata/ + quality_analysis/ + archive/ (30 дней ротация)
```

**Результат:**
- Защищённые транскрипции (PII замаскированы)
- Оценки качества (0-100 баллов по 30 критериям)
- Детальные рекомендации для обучения
- Автоматические отчёты руководителям
- **Dashboard с апсейл метриками и рейтингами**
- **Всё бесплатно (100% локально!)**

### Dashboard не обновляется
```
# Ручное обновление для проверки
./venv/bin/python main.py update-dashboard

# Проверка автоматического планировщика (23:00)
# Смотрите logs/asr-watcher.log
```

### Дубликаты в Google Sheets
```
# Проверка дубликатов (dry run)
./venv/bin/python main.py cleanup-sheets

# Удаление дубликатов
./venv/bin/python main.py cleanup-sheets --apply
```
**Примечание:** Система защищена от дубликатов. Повторная обработка файлов не создаёт дубликаты.

### Битые аудиофайлы в карантине
```
# Проверка карантина
ls -lh quarantine/

# Файлы с префиксом:
# CORRUPTED_* - повреждённые MP3 (invalid MPEG header)
# TOO_LARGE_* - превышен лимит размера
# ERROR_*     - другие ошибки обработки
```

**Восстановление JSON-wrapped файлов:**
```bash
# Если файлы от Asterisk/VoIP систем (JSON формат)
./venv/bin/python restore_from_quarantine.py
```

**Примечание:** Система автоматически поддерживает:
- ✅ JSON-wrapped MP3 (Asterisk/VoIP)
- ✅ Сырые MP3/WAV/M4A
- ✅ Автоматическое base64 декодирование

## 📊 Архитектура

### Главный Pipeline (daemon_watcher.py):

1. **Watchdog** - мониторинг input/ (inotify events)
2. **Worker Queue** - обработка файлов (последовательно, безопасно для памяти)
3. **ASR** - транскрибация (Whisper Large V3)
4. **VLLM** - маскирование + классификация (Qwen3-30B)
5. **Quality** - анализ качества (30 критериев)
6. **Analytics** - сохранение в SQLite
7. **Sheets** - real-time обновление Google Sheets

### Планировщики (daemon threads):

- **03:00** - автоочистка archive/ (30 дней ротация)
- **23:00** - батчевая синхронизация + обновление Dashboard
- **09:00** - Telegram daily отчет
- **Пн 10:00** - Telegram weekly отчет

### Аналитика (3 слоя):

1. **SQLite** - error_events + calls_summary (быстрые запросы)
2. **Витрины** - day/week агрегаты (JSON) с апсейл метриками
3. **Отчёты** - Telegram + Google Sheets + CSV
