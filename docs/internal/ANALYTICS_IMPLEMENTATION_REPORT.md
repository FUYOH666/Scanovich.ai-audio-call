### **ЗАГОЛОВОК СЕКЦИИ:**

```
📊 АНАЛИТИЧЕСКАЯ ПАНЕЛЬ
```

### **АВТОМАТИЧЕСКИЕ ФОРМУЛЫ:**
| Метрика | Формула Google Sheets | Описание |
|---------|----------------------|----------|
| **Кол-во входящих** | `=COUNTA(A2:A{last_row})` | Общее количество звонков |
| **Кол-во записавшихся** | `=COUNTIF(AB2:AB{last_row},"да")` | Успешные записи |
| **Упущенные из-за нарушения скрипта** | `=SUMPRODUCT((AA2:AA{last_row}<15)*(AB2:AB{last_row}="нет"))` | Низкий балл + не записался |
| **Не записавшиеся при соблюдении скрипта** | `=SUMPRODUCT((AA2:AA{last_row}>=15)*(AB2:AB{last_row}="нет"))` | Высокий балл + не записался |
| **% конверсии звонок-запись** | `=IF(B{row}>0,B{row+1}/B{row}*100,0)` | Процент записавшихся |
| **% соблюдения скрипта** | `=AVERAGE(AA2:AA{last_row})/20*100` | Средний балл в процентах |

- **🤖 Выводы:** Конкретные рекомендации для улучшения конверсии

## 🎯 **ЛОГИКА АНАЛИТИКИ:**

### **РАСЧЕТ УПУЩЕННЫХ ПАЦИЕНТОВ:**
```
Логика: Если балл < 15 И пациент не записался = упущен из-за нарушения скрипта
Формула: SUMPRODUCT((балл<15)*(записался="нет"))
```

### **РАСЧЕТ ОБЪЕКТИВНЫХ ОТКАЗОВ:**
```
Логика: Если балл >= 15 И пациент не записался = объективный отказ
Формула: SUMPRODUCT((балл>=15)*(записался="нет"))
```

### **LLM АНАЛИЗ ВКЛЮЧАЕТ:**
- Оценку общего качества работы команды
- Выявление основных проблем и тенденций  
- Сравнение с индустриальными стандартами
- Персонализированные рекомендации
