## 🔄 ПОШАГОВЫЙ ПРОЦЕСС ОБРАБОТКИ ЗВОНКА

### ⚡ **ЭТАП 0: ЗАПУСК БАТЧ-ОБРАБОТКИ**
```bash
python batch_process.py input/
```

**ЧТО ПРОИСХОДИТ:**
- Сканирует папку `input/` на наличие `.mp3/.wav` файлов
- Инициализирует GPU оптимизатор и платформо-менеджер
- Создает изолированные LM Studio сессии для каждого файла
- Запускает enhanced_pipeline_v3.py для каждого файла

---

### 🎤 **ЭТАП 1: ТРАНСКРИБАЦИЯ (offline_pipeline.py)**

**МОДЕЛЬ:** WhisperX Large-v3  
**НАСТРОЙКИ:**
```python
model_size = "large-v3"
device = "cuda" if torch.cuda.is_available() else "cpu"
batch_size = 16
compute_type = "float16"
```

**ЧТО ПРОИСХОДИТ:**
1. **Загрузка аудио** → Конвертация в WAV 16kHz
2. **WhisperX транскрибация** → Получение временных меток
3. **Сохранение в JSON** → `output/transcriptions/call_X_transcription.json`

**РЕЗУЛЬТАТ:**
```json
{
  "segments": [
    {"start": 0.0, "end": 3.2, "text": "Добрый день, клиника МРТ-Лидер"},
    {"start": 3.5, "end": 7.1, "text": "Меня зовут Алёна, чем могу помочь?"}
  ]
}
```

### 🧠 **ЭТАП 2: LLM АНАЛИЗ (unified_pipeline.py)**

**МОДЕЛЬ:** LM Studio (локальная LLM)  
**ПРОМПТ-СИСТЕМА:** 3-этапная обработка

#### 🔄 **ШАГ 2.1: ПОСТОБРАБОТКА ТРАНСКРИПЦИИ**
**ФАЙЛ:** `transcription_postprocessor.py`  
**ПРОМПТ:**
```
Исправь ошибки транскрипции в тексте звонка медицинской клиники МРТ-Лидер.
Сохрани смысл, исправь только явные ошибки распознавания речи.

ОРИГИНАЛ: {transcription}
ИСПРАВЛЕННЫЙ:
```

#### 🔄 **ШАГ 2.2: СЕМАНТИЧЕСКАЯ ДИАРИЗАЦИЯ**
**ПРОМПТ:**
```
Определи кто говорит в каждом сегменте: АДМИНИСТРАТОР или КЛИЕНТ.
Учитывай контекст медицинской клиники МРТ-Лидер.

ТРАНСКРИПЦИЯ: {corrected_text}

РЕЗУЛЬТАТ в формате:
АДМИНИСТРАТОР: "текст"
КЛИЕНТ: "текст"
```

#### 🔄 **ШАГ 2.3: АНАЛИЗ СКРИПТА (20 КРИТЕРИЕВ)**
**ПРОМПТ:** 
```
Проанализируй звонок медицинской клиники по 20 критериям скрипта продаж.
Оцени каждый критерий: 0 (не выполнен) или 1 (выполнен).

КРИТЕРИИ:
1. приветствие - Поздоровался и назвал клинику
2. название_клиники - Упомянул "МРТ-Лидер"
3. фио_администратора - Представился по имени
4. имя_пациента - Спросил как обращаться
5. блок_опроса - Выяснил симптомы/проблему
6. презентация_исследования - Объяснил что такое МРТ
7. комплекс_предложен - Предложил дополнительные услуги
8. цена_озвучена - Назвал стоимость услуг
9. структура_скрипта - Логичная последовательность
10. возражение_обработано - Ответил на сомнения
11. фио_записано - Записал ФИО пациента
12. дата_рождения - Уточнил дату рождения
13. номер_телефона - Записал номер телефона
14. дата_время_записи - Назначил дату и время
15. адрес_клиники - Сообщил адрес
16. паспорт_документы - Напомнил о документах
17. диск_озвучен - Предложил запись на диск
18. подготовка - Объяснил подготовку к МРТ
19. вежливость - Был вежлив и приятен
20. профессионализм - Проявил компетентность

ДИАРИЗОВАННЫЙ ТЕКСТ: {diarized_text}

ОТВЕЧАЙ СТРОГО В JSON:
{
  "администратор": "Имя",
  "приветствие": {"score": 0/1, "comment": ""},
  "название_клиники": {"score": 0/1, "comment": ""},
  ...
  "общая_оценка": X,
  "комментарии": "Общий анализ работы",
  "бизнес_анализ": "Рекомендации по улучшению продаж"
}
```

### 📊 **ЭТАП 3: ИЗВЛЕЧЕНИЕ ДАННЫХ (unified_data_extractor.py)**

**ЧТО ПРОИСХОДИТ:**
1. **Парсинг JSON** → Структурированные данные
2. **Извлечение бизнес-сущностей:**
   - Имя администратора
   - ФИО пациента  
   - Номер телефона
   - Дата рождения
   - Услуги и стоимость
   - Дата/время записи
   - Результат звонка

3. **Преобразование оценок** → 0/1 → "Нет"/"Да"
4. **Создание row_data** → 29 колонок для Google Sheets

### 📈 **ЭТАП 4: GOOGLE SHEETS (google_sheets_integration.py)**

**ФУНКЦИЯ:** `add_standardized_data_to_sheet()`

**СТРУКТУРА GOOGLE ТАБЛИЦЫ (29 колонок):**
```
A: Дата | B: Время | C: Длительность | D: Администратор | E: Тип звонка
F-T: Критерии скрипта (15 колонок) - Да/Нет
U-Y: Доп. критерии (5 колонок) - Да/Нет  
Z: Итог звонка | AA: Записался | AB: Комментарии | AC: Балл
```

**ГЕНЕРАЦИЯ КОММЕНТАРИЕВ:**
```python
def _generate_enhanced_comments():
    sections = []
    
    # 1. ТОЛЬКО ПРОБЛЕМЫ (если score = 0)
    if problems:
        sections.append(f"❌ НЕДОЧЕТЫ: {problems}")
    
    # 2. АНАЛИЗ ИИ ИЗ JSON
    if ai_comment:
        sections.append(f"💭 АНАЛИЗ ИИ: {ai_comment}")
    
    # 3. БИЗНЕС-РЕКОМЕНДАЦИИ ИЗ JSON  
    if business_analysis:
        sections.append(f"📈 РЕКОМЕНДАЦИИ: {business_analysis}")
    
    # 4. КРИТЕРИИ (только если проблемы)
    if вежливость == 0:
        sections.append("😊 ПРИЯТНЫЙ РАЗГОВОР: Не перебивать, вежливые обороты")
    
    return " ║ ".join(sections)
```
