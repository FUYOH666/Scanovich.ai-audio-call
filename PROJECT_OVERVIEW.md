## 🎯 Описание проекта

**ASR Call Quality Analyzer** — это **production-ready система** автоматического анализа качества обслуживания клиентов на основе записей телефонных разговоров.

### Ключевые возможности:

- ✅ **Автоматическая транскрипция** аудиозвонков (Whisper Large V3)
- ✅ **Маскирование персональных данных** (PII) — ФИО, телефоны, адреса
- ✅ **Анализ качества** по 30 критериям корпоративных скриптов
- ✅ **Апсейл-метрики** — отслеживание упущенной выручки
- ✅ **Автоматические отчеты** — Telegram, Google Sheets, CSV
- ✅ **Рекомендации для обучения** — конкретные действия для улучшения
- ✅ **100% локальное решение** — без внешних API, полный контроль данных

### Текущее применение:

**Сеть диагностических центров** (4 филиала в разных городах):
- 4 филиала
- ~80 звонков/час
- ~57,600 звонков/месяц
- 24/7 мониторинг качества обслуживания

## 💡 Проблема и решение

### Проблема:

**Традиционный контроль качества:**
- ❌ Ручное прослушивание звонков (5-10 мин на звонок)
- ❌ Субъективная оценка (зависит от настроения проверяющего)
- ❌ Выборочная проверка (1-3% звонков)
- ❌ Отсутствие оперативной обратной связи (недели задержки)
- ❌ Высокая стоимость (зарплата QA-специалистов)
- ❌ Невозможность масштабирования

**Коммерческие решения:**
- ❌ Высокая стоимость ($0.05-0.15 за минуту через API)
- ❌ Зависимость от внешних сервисов
- ❌ Риски утечки данных (передача в облако)
- ❌ Ограничения по объему (квоты, rate limits)

### Решение ASR Call Quality Analyzer:

**Автоматизированная система:**
- ✅ **100% охват** — каждый звонок анализируется
- ✅ **Объективная оценка** — по 30 критериям скриптов
- ✅ **Мгновенная обратная связь** — отчеты на следующее утро
- ✅ **Низкая стоимость** — $0 за обработку (только GPU)
- ✅ **Масштабируемость** — до 100K+ звонков/месяц на одном GPU
- ✅ **Безопасность** — все данные локально, PII маскируются
- ✅ **Конкретные рекомендации** — для обучения персонала

**Экономический эффект:**
- **Экономия:** $51,287/год vs Commercial LLM API API
- **ROI:** 2 недели (окупаемость GPU RTX 5090)
- **Производительность:** 37x быстрее реального времени

## 🛠️ Технологический стек

### Основные технологии:

#### 1. **Транскрипция (ASR)**
- **Модель:** OpenAI Whisper Large V3
- **Библиотека:** faster-whisper (CTranslate2 оптимизация)
- **Производительность:** RTF 0.027 (37x быстрее реального времени)
- **Точность:** WER ~5-8% для русского языка
- **Устройство:** CUDA (NVIDIA GPU)

#### 2. **Постобработка и анализ (LLM)**
- **Модель:** Large Language Model (30B parameters) (AWQ 4-bit квантизация)
- **Сервер:** vLLM (OpenAI-compatible API)
- **Контекст:** 16K токенов (достаточно для 17+ мин звонков)
- **VRAM:** ~30GB из 32GB (RTX 5090)
- **Функции:**
  - Маскирование PII (ФИО, телефоны, адреса)
  - Классификация звонков
  - Анализ качества по 30 критериям
  - Генерация рекомендаций

#### 3. **Backend**
- **Язык:** Python 3.12
- **Фреймворк:** Asyncio + Watchdog (inotify)
- **БД:** SQLite (аналитика, события ошибок)
- **Логирование:** Python logging + journalctl (systemd)

#### 4. **Интеграции**
- **Telegram Bot API** — автоматические отчеты
- **Google Sheets API** — Dashboard и детализация
- **Asterisk/VoIP** — загрузка записей из АТС (4 источника)

#### 5. **Инфраструктура**
- **OS:** Ubuntu 22.04 LTS
- **GPU:** NVIDIA RTX 5090 (32GB VRAM)
- **CUDA:** 12.4+
- **Systemd** — управление сервисами (daemon mode)
- **Git** — версионирование (GitHub private repo)

### Модели монетизации:

#### 1. **SaaS (Software as a Service)**

**Модель:** Подписка на облачное решение

**Тарифы:**
- **Starter:** $99/месяц (до 5K звонков)
- **Business:** $299/месяц (до 20K звонков)
- **Enterprise:** $999/месяц (до 100K звонков)
- **Custom:** индивидуальные условия (100K+ звонков)

**Преимущества:**
- Быстрый старт (без установки)
- Масштабируемость
- Автоматические обновления

**Недостатки:**
- Зависимость от облака
- Риски утечки данных
- Ограничения по объему

#### 2. **On-Premise (локальная установка)**

**Модель:** Продажа лицензии + поддержка

**Тарифы:**
- **Лицензия:** $10,000 (единоразово)
- **Поддержка:** $2,000/год (обновления, консультации)
- **Установка:** $2,000 (настройка, обучение)

**Преимущества:**
- Полный контроль данных
- Безопасность (все локально)
- Неограниченный объем

**Недостатки:**
- Высокий порог входа
- Требуется GPU
- Самостоятельное обслуживание

#### 3. **Hybrid (гибридная модель)**

**Модель:** Локальная установка + облачная аналитика

**Тарифы:**
- **Лицензия:** $5,000 (единоразово)
- **Подписка:** $199/месяц (облачная аналитика, отчеты)
- **Поддержка:** $1,000/год

**Преимущества:**
- Баланс безопасности и удобства
- Гибкость
- Масштабируемость

#### 4. **White Label (OEM)**

**Модель:** Продажа технологии партнерам

**Тарифы:**
- **Лицензия:** $50,000 (единоразово)

- **Поддержка:** индивидуально

- Фокус на R&D

### 1. **100% локальное решение**

**Преимущество:**

- Нет зависимости от внешних API
- Неограниченный объем обработки
- $0 за обработку (только GPU)

**Конкуренты:**
- Yandex SpeechKit (облако, $0.05/мин)
- Google Cloud Speech-to-Text (облако, $0.024/мин)
- Azure Speech Services (облако, $0.016/мин)
- Commercial-LLM API (облако, $0.003/1K токенов)

### 2. **Высокая производительность**

**Преимущество:**
- RTF 0.027 (37x real-time)
- ~45 секунд на звонок (полный цикл)
- До 100K+ звонков/месяц на одном GPU

**Конкуренты:**
- Традиционные решения: 5-10 мин на звонок (ручная проверка)
- Облачные API: зависимость от сети, rate limits

### 3. **Объективная оценка по скриптам**

**Преимущество:**
- 30 критериев (детальная оценка)
- Адаптация под корпоративные скрипты
- Конкретные рекомендации для обучения

**Конкуренты:**
- Субъективная оценка (зависит от проверяющего)
- Общие метрики (длительность, количество)
- Нет рекомендаций

### 4. **Апсейл-метрики**

**Преимущество:**
- Отслеживание упущенной выручки
- Видеозаключение, допродажи, цена
- Конкретные действия для увеличения чека

**Конкуренты:**
- Нет апсейл-метрик
- Только контроль качества

### 5. **Автоматизация 24/7**

**Преимущество:**
- 100% охват звонков
- Мгновенная обратная связь (отчеты на следующее утро)
- Нет человеческого фактора

**Конкуренты:**
- Выборочная проверка (1-3%)
- Задержка обратной связи (недели)
- Субъективность

### 6. **Низкая стоимость**

**Преимущество:**
- $0 за обработку (только GPU)
- ROI 2 недели (окупаемость GPU)
- Экономия $51K/год vs Commercial-LLM API

**Конкуренты:**
- Высокая стоимость ($0.05-0.15/мин)
- Зависимость от квот и rate limits
